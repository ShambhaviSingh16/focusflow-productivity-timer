# FocusFlow – Distraction-Free Study & Work Timer

FocusFlow is a modern productivity web application designed to help students and professionals stay focused while studying or working.
It uses the **Pomodoro Technique**, a proven time-management method that breaks work into focused intervals followed by short breaks.

The goal of FocusFlow is to provide a **simple, distraction-free environment** where users can manage tasks, track focus sessions, and improve productivity.

## ✨ Features

* ⏱ **Pomodoro Timer**

  * 25-minute focus session
  * 5-minute break timer

* ▶ **Timer Controls**

  * Start
  * Pause
  * Reset

* 📝 **Task Management**

  * Add tasks
  * Mark tasks as completed
  * Delete tasks

* 📊 **Daily Progress Tracking**

  * Number of completed focus sessions
  * Total time focused

* 🎯 **Motivational Messages**

  * Dynamic messages during focus sessions to keep users motivated

* 📱 **Responsive Design**

  * Works smoothly on desktop and mobile devices

---

## 🖥️ Application Interface

FocusFlow provides a clean and minimal interface with three main sections:

1. **Focus Timer**
   A visual countdown timer with a progress ring for focus and break sessions.

2. **Task Manager**
   Users can add tasks and mark them as completed to keep track of their work.

3. **Daily Progress Dashboard**
   Displays completed focus sessions and total time spent focusing.
